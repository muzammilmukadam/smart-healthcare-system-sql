# Smart Healthcare System — SQL Project

## Project Overview

A database management project built using MySQL to organize healthcare information, including patients, doctors, departments, appointments, medical records, and medicines.

## Objectives

* Organize healthcare data in a relational database.
* Manage patient and appointment information.
* Retrieve and analyze related records using SQL queries.
* Practice database design and SQL programming.

## Technologies Used

* **Database:** MySQL
* **Language:** SQL

## Database Components

The project includes tables for patients, doctors, departments, appointments, medical records, and medicines.

## SQL Concepts

* **JOINs:** Retrieve related information from multiple tables.
* **GROUP BY:** Group records for summary analysis.
* **CASE expressions:** Apply conditional logic in queries.
* **Stored procedures:** Create reusable database operations.
* **Relational database design:** Organize data into related tables.

## Stored Procedures

* `show_patients()` — Retrieves patient records.
* `patients_by_city(city_name)` — Retrieves patients based on city.

## How to Run

1. Install MySQL Server and open MySQL Workbench.
2. Download `smart_healthcare_system.sql` from this repository.
3. Open the SQL file in MySQL Workbench.
4. Execute the script and inspect the database objects and queries.

## Learning Outcomes

This project demonstrates practical SQL skills, relational database design, data retrieval, aggregation, and stored procedure creation.
